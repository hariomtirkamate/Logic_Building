## Getting Started

### Prerequisites
- GCC (for C programs)
- G++ (for C++ programs)
- JDK 8 or higher (for Java programs)

### Clone the repository
```bash
git clone https://github.com/hariomtirkamate/Logic_Building.git
cd Logic_Building
```

### Compile and run

**C**
```bash
gcc Program1.c -o program1
./program1
```

**C++**
```bash
g++ program2.cpp -o program2
./program2
```

**Java**
```bash
javac program3.java
java program3
```

> On Windows, run the compiled file with `program1.exe` instead of `./program1`.
